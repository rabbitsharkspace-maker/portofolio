# Archived components

Everything the site used to be built out of: the ReactBits-style effect
catalogue (TextPressure, ScrambledText, GlareHover, PixelTrail, LiquidChrome,
ElectricBorder, GooeyNav, ClickSpark, CircularGallery…), the three animated
backgrounds (Aura, Meadow, Ferrofluid), the scroll-driven RocketStage hero, the
GLB character rigs (JennyPeek, CharacterModel, ModelViewer) and the several
generations of work wall (WorkCard, WorkEmbeds, WorkGallery, WorkWheel).

Nothing here is imported. It is kept rather than deleted because some of it is
genuinely nice work and may be wanted back for one specific moment — but the
reason it left is worth remembering: thirty effect components is the most
recognisable house style on the internet right now, and a studio whose whole
argument is "we are two specific people" cannot afford to look like a template.

If you bring one back, bring it back for a job. The test: turn the effect off,
and if the page says exactly the same thing about you, it was decoration.

Their mutual imports still resolve from this folder (same depth as
`src/components/`), so a file can be moved straight back.
